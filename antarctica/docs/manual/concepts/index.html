Basic concepts

The Conductor

The conductor sets the mood of the piece. There are three axes: order to chaos, sparse to busy, melodic to dissonant. By default, the conductor moves those three axes constantly. The values from the conductor can affect track sounds, notes, effects parameters, and the overall key.

Tracks

Tracks generate sound, and can change the timbral quality of the sound and the notes played at intervals called decision points. You can lock any or all track parameters to prevent them from changing.

Auto and Manual

Each track has two types of parameters:

  • Mixer parameters:

    • Level
    • Pan
    • Effects send levels
    • Mute and Solo

    You always set these. The track does not change them.

  • Sound parameters:

    • Generator type
    • Timbral controls
    • Filter + filter LFO
    • Sequence parameters

    All parameters can be Auto or Manual.

In Auto, the track chooses the value. It will choose new values over time if you let it. In Manual, you choose. The value stays where you set it until you change it.

NoteThe Auto/Manual state of each parameter is saved in presets and in your DAW project. It is not a parameter that a DAW can automate.

The seed

All the random choices in Antarctica come from one number—the seed. Without user input, the same seed settings always create the same music.

You can use this to:

  • Return to a result you like and write down the seed.
  • Share a result with a different person, such as giving them the seed and preset.
  • Export the same music you heard. See Export audio.

The conductor, tracks, and effects use a different random stream each. Changing one track does not change the choices of the other tracks.

Effects

Sounds generated by tracks may be sent through the effects section for extra color and interest.

Signal flow

Each track goes Generator → Filter & LFO → Envelope → Level → Pan. Then it goes to the main mix and to the reverb and delay sends. The delay can feed the reverb. Both effects return to the main mix, then Master Gain, then Output.

The sends occur after Level and Pan. Mute and Solo also stop the sends. Turn on Pre below a send to take it before Level.
