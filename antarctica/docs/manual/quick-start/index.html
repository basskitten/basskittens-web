Quick start

  1. Open Antarctica.
  2. Click Play in the toolbar, or push the Space bar.
  3. Listen. The tracks fade in and start to make decisions.
  4. To hear a different mood, open the preset menu in Preset & Output and select a factory preset.
  5. To hear new random choices with the same settings, click New Seed.
  6. To set the mood yourself, turn off Auto in the Conductor panel then adjust the three sliders.
