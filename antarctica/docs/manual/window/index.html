The window

The window (from top to bottom):

  1. Aurora: the visualization. Display or hide it.
  2. Conductor row: Conductor, Tuning, Clock, FM Patches, and Preset & Output.
  3. Effects row: Reverb and Delay.
  4. Track strips: one mixer strip for each track.
  5. Detail panel: the generative parameters of the selected track.

In the standalone app, the toolbar includes Play/Stop, Record, Sleep Timer, and Export Audio buttons.

Hover the pointer over a control to see help text.
