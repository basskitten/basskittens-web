# Screenshots

Put these PNG files in this folder. Until a file exists, the page shows a dashed box with its name. Use a 2× (Retina) capture, dark window, while the app plays.

- `aurora.png`: The Aurora band while many tracks play, with a mix of generator colors.
- `conductor.png`: The Conductor panel with Auto on (the axes show bars, not sliders). The Hold button is in the header.
- `decision-ring.png`: A close-up of one strip's header: the decision ring (partly empty) and the step light.
- `effects.png`: The Reverb and Delay panels.
- `export-sheet.png`: The Export Audio sheet, before you click Export (Length, Fade Out, Seed fields).
- `fm-patches.png`: The FM Patches panel after a DX7 bank import (bank name and patch count visible).
- `main-window-labeled.png`: The full window. Add numbered labels for: 1 Aurora, 2 Conductor row, 3 Effects row, 4 Track strips, 5 Detail panel, 6 Toolbar.
- `main-window.png`: The full app window with the Aurora visualization on, at default size, while it plays.
- `preset-output.png`: The Preset & Output panel, with the preset menu open (Factory and User sections).
- `track-detail.png`: The detail panel of one track, with some parameters in Manual (amber names) and some in Auto.
- `track-strip.png`: One track strip, close up, while it plays a sequence, with 2 or 3 parameters in Manual (amber lock count visible).
- `track-strips.png`: The row of eight track strips, with some tracks playing and some resting.
- `tuning.png`: The Tuning panel with System set to Auto, and the 'Playing … on …' line.
